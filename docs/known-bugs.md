# Known bugs

This file records every bug the properties found. An open bug has a filter that discards the cases failing with its signature, so the properties keep looking for other bugs. A fixed bug has no filter, and its row stays here with the pull request that fixed it and the arrow-rs commit a run without the filter checked. Each issue or comment filed from these properties carries a minimal reproduction. apache/arrow-rs#10925 and apache/arrow-rs#10990 were filed by others before the properties found them.

Run with `ARROW_PBT_NO_KNOWN=1` to turn every filter back into a failure. See [workflow.md](workflow.md) for adding filters and for removing them when a fix lands.

## Expected behavior, not bugs

Some discards are not bugs. They mark inputs outside a kernel's documented domain or outside a law, and the reasons say so: `outside the domain: ...`, `outside the law: ...`, `unsupported: ...`, `IPC does not support this type`, `cast not supported`. Behavior that a maintainer settled is encoded in the property itself, with a comment citing the issue:

- Integer to `Time` and `Date64` casts keep out-of-range values (apache/arrow-rs#5288).
- `T::Native::MIN` is an unsupported operand of decimal division (apache/arrow-rs#10911).
- `take` with a null index into a type that cannot hold a null returns an error (apache/arrow-rs#10994).
